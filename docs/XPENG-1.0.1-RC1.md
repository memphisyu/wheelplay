# Wheelplay 小鹏定制版 1.0.1 候选版

基于 1.0 合入 fython/wheelplay main 的 b894ca9、3e726dc 与合并提交 5c5b080。保留 1.0 的 MSE 音乐、浏览器封面、Root 后台准备连接和比例容差。应用名称不变，versionCode 31，versionName 1.0.1-rc.1，采用 Release 构建。

更新：音频解码输入拥塞时先排出输出并限时重试；修正 Opus RTP 时钟、播放反馈与麦克风上行时间戳；原生 Android 媒体信息/封面去重；有线 VPN 限定本应用；MIUI 旧蓝牙权限兼容；设置页保留 DiPlay 来源说明。没有新增 AAC 直通，也不是针对后台自启动的新修复。

沿用包名与签名，可覆盖 1.0 并保留数据；公开 APK 不内置认证资源。验证音乐长时间播放与快速切歌、封面/歌曲信息、方向盘控制、浏览器麦克风/Siri/通话、锁屏自动连接、比例变化与断连恢复。有线用户另验证 VPN 和 USB 重连。记录车机/手机系统版本和连接方式，异常导出诊断。

1.0 正式版保持发布状态。候选版需实车反馈后再转正式；Android 降版本通常不能直接覆盖，卸载会清除数据，保留好认证资源与 HTTPS 证书原文件。
