# 1.0.1 RC2 画面适配修复

修复 audio9 / 1.0 引入的尺寸适配回归：此前仅按宽高比判断，并容忍 20% 的比例变化，导致分屏沿用旧画面产生大黑边，同等比例放大窗口也不重新协商画面尺寸。

现在仅在宽、高各变化不超过 3%，且宽高比变化不超过 2% 时保留会话。明显的分屏、全屏变化恢复重新协商；保留尺寸上报去抖和隐藏页面过滤。画面仍等比例显示，触控映射保持原逻辑。真正的尺寸变化可能引起一次重新连接，这是当前协议适配的取舍。

网页诊断新增可视区域宽高、设备像素比和流尺寸，便于区分旧画面放大与图标/文字大小设置。沿用 RC1 上游可靠性修复、封面、方向盘媒体控制及后台连接功能。包名和签名不变，versionCode 32，可覆盖安装 1.0 或 RC1。

实车验证：先保持原有图标/文字大小与分辨率设置，分别启动分屏、切换全屏、再返回分屏，等待重新连接完成。检查黑边、图标、触控落点和媒体控制。若图标仍偏大，请记录 App 图标/文字大小与分辨率设置，并导出网页诊断。构建和自动化检查不能替代 G9 + OnePlus 15T 实车验证。
