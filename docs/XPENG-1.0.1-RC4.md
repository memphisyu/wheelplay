# 1.0.1 RC4 审查修复

基于本地 RC3，保留其窗口容差、4 秒尺寸稳定等待、服务 sticky 恢复与停止原因日志。versionCode 34，沿用原包名及签名，可覆盖 RC2/RC3，不重置配置。

- 重协商异步关闭完成后使用最新 activeDisplaySize，避免关闭期间收到新尺寸却仍按旧尺寸启动。
- 旧代次的会话结束回调在修改全局状态前退出，避免污染新会话。
- 浏览器手势会恢复非 running 的 AudioContext，并允许上一次恢复被拒绝后再次重试；不再仅依据 playback 标志跳过恢复。
- MSE 接收 300/500/1000ms 缓冲目标；起播和欠载后等待所选缓冲积累，更新缓冲设置保留当前播放器和时间线；延迟追赶使用目标缓冲。自动播放被拒绝后等待用户点按重试。
- 浏览器 VM 测试夹具按依赖顺序加载实际模块源码，补齐必要的模拟 DOM/定时器接口；恢复全量配对、触控与重连测试入口。此类测试仍是模拟浏览器，不替代真实 Chrome。

验证：全部浏览器测试共 97 项通过，包括 FLAC MP4 经 ffmpeg 解码后的逐样本一致性、暂停后恢复重试、三档 MSE 起播/欠载恢复、运行时缓冲目标变更。Android 单元测试 507 项通过，总计 604 项；Release 构建成功，完整静态检查 0 错误、23 条警告。尺寸竞争条件采用代码路径审查修复，尚无真实设备时序复现测试。

实车重点：连续播放音乐与视频；切换分屏/全屏并等待稳定；浏览器离开再返回后点按恢复；尝试三档缓冲（延迟和抗抖动有取舍）；验证封面、方向盘控制、锁屏后台连接。不要仅根据静态检查或单元测试认定实车断连已完全解决。
