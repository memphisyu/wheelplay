# 1.0.1 RC6：App 内双渠道更新

入口：设置 → 应用更新。默认 Gitee（国内），可切换 GitHub；RC 版本初次默认包含预发布，也可关闭，仅检查正式版。选择会保存在本机。检查和下载由用户手动发起，不会启动时联网或自动安装。

## 使用流程

1. 选择渠道和版本范围，点击检查更新。
2. 查看版本说明并确认下载。APK 由系统下载管理器处理，可在通知栏查看；离开 App 后下载继续，返回可恢复任务进度，也可取消并清除更新包后换渠道。
3. 下载完成后点击“校验并安装更新”。应用将文件复制到私有更新目录，验证 SHA-256、包名、递增 versionCode、发行版版本号及当前应用签名。
4. 首次使用需在系统界面允许本应用安装未知应用；返回后再次点击安装。安装由系统确认，会中断当前投屏并重启应用，请停车后操作。不使用 Root 静默安装。

当前 RC6 比仓库中已公开的 RC5 新，因此检查到“该渠道没有更新版本”是正常结果。需要 RC7 或更高版本发布后才能从 RC6 升级。后续发行版必须保留对应 APK 和 `标签.sha256` 校验附件，APK 文件名不限于固定版本，但只能有一个 APK。

## 实现与验证范围

- 使用两个平台的公开 Releases API，无需用户登录或提供 Token。分页读取，按语义版本排序；不依赖 Gitee 的列表顺序。正式版优先于同版本 RC，RC10 高于 RC9；不提示降级。
- 下载源固定为 memphisyu/wheelplay 对应平台的发行版路径。多 APK、缺少校验附件或无法识别的历史标签不自动选取。网络失败不冒充“已是最新版”。
- 校验通过的私有副本由仅共享 updates 目录的 FileProvider 交给安装器；认证资源、证书或其他应用数据不会共享。校验或包签名不匹配则拒绝安装。安装 Intent 不会进入本 App 的认证 APK 导入入口。
- 覆盖版本排序、草稿/RC 筛选、真实平台响应样本、分页、断网、校验文件解析、文件损坏、私有目录复制、包名/签名/版本不匹配及更新界面偏好恢复。浏览器音频与媒体回归测试保持通过。
- 版本 1.0.1-rc.6，versionCode 36；沿用现有包名与签名，可覆盖 RC5。共 622 项独立检查通过：全量 Android 519 项、浏览器 102 项，以及补充的下载恢复场景 1 项；后者和既有 UI 场景一起通过定向回归。Release 静态检查 0 错误、23 条警告。系统下载与系统安装器的 OnePlus 15T / OPPO 实机交互仍需验证。

本版本保留 RC5 的音乐中断修复、封面、方向盘控制及画面适配，不修改音视频协议或 Root 保活策略。构建包与源码、校验文件见本地交付；未自动发布发行版。
