# 1.0.1 RC7：上游可靠性与免 Root 浏览器兼容

以 RC6（67791a9）为基础整合上游 39485f9（PR #13、#14）。保留小鹏版的网页音乐、媒体信息、封面、方向盘控制、尺寸容差、Root 保活、HTTPS 与 App 内双渠道更新。

- 新增默认关闭的「Tesla 兼容（实验）→ 连接方案 → 免 Root VPN（实验）」，需要用户在前台授权 Android VPN，无需 Root / Shizuku。开启手机系统热点并让车机连接后，以设置中显示的兼容 IP 与实际 Web 端口访问。也可用于有相同局域网地址访问限制的其他车型，尚待实车验证。
- 该模式只处理兼容访问地址，默认仍是 `http://6.6.6.6:8080`，不提供免 Root 的 80 / 443 映射。对于确实只允许低端口的车机，不能承诺解决。详见 TESLA_HTTP.md。
- 无线启动增加首次 TCP 看门狗、受限重试、地址族恢复和有认证蓝牙控制的交接保留；重试耗尽会停止并等待手动操作。
- 麦克风输入增加初始化回退与有限读错恢复；系统 Opus 不可用时采用 Concentus 软件回退并保留许可。这是麦克风上行兼容，不改变音乐下行编码协议。
- 同一上游可靠性提交包含 USB 分帧/读取/配置回退修复，一并整合以保持控制器依赖完整；有线设备需要独立实测。
- 合并冲突保留小鹏后台服务、锁屏保护、应用更新及设置。启动 Root 检查同时尊重独立 Root 保活和已启用 Root 路由；仅使用 VPN 的非 Root 用户不会因启动例行请求 Root。
- 包名和签名沿用，版本为 1.0.1-rc.7 / versionCode 37。可覆盖安装，勿卸载或清除数据。新版本安装后重新打开车机网页。

VPN 兼容依赖部分 ROM 对已停用 TUN 地址的保留行为，占用 Android VPN 槽位；不能保证与其他 VPN 共存。地址本机可见不等于车机能访问。HTTPS 仍需可信证书，WebRTC 需独立验证。

验证结果与 APK 校验信息见本地 RC7 构建记录。此候选尚未发布 GitHub/Gitee。

验证：Android 719 项、网页 102 项全部通过；Release 构建成功，静态检查 0 错误、23 条警告。新增测试覆盖独立 Root 保活与 VPN 模式的启动权限策略。手机/车机实际 VPN 地址与热点可达性未验证。
