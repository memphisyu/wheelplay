# Wheelplay 小鹏定制版 1.0.1 正式版

基于已验证的 RC7 功能基线（b1174e8），按维护者要求提升为正式版。versionName 1.0.1 / versionCode 38，沿用原包名与签名，可覆盖 1.0 和已有 RC 版。

## 更新
- App 内更新：设置 → 应用更新，支持 GitHub / Gitee（国内），系统后台下载、进度恢复、完整性与包名/签名/版本校验，再由系统确认安装。不自动静默安装。
- 音乐：修复播放请求被 pause 中断后进度继续但无声、旧错误提示残留，保留歌曲信息、封面及方向盘控制。
- 画面：保留小幅尺寸容差及稳定等待，修复尺寸重协商时序；明显分屏/全屏变化仍可能重连。
- 上游可靠性：整合至 39485f9，包括首次 TCP 看门狗、受限无线恢复、地址族选择、蓝牙控制交接保护、麦克风恢复和软件 Opus 回退、USB 分帧及读写兼容。软件 Opus 用于麦克风上行，不是音乐 AAC 直通。
- 可选免 Root VPN：默认关闭，需前台 Android VPN 授权，不需要 Root / Shizuku。原 Root 路由与独立小鹏 Root 保活继续保留。

## 免 Root 浏览器兼容的边界
此模式旨在帮助有私有网段地址限制的车机浏览器访问本地服务。手机开启系统热点，车机连接手机，再按 App 显示的兼容地址访问；默认示例为 http://6.6.6.6:8080。

它不提供免 Root 的 80 / 443 映射。仅知 8080 / 8443 被拒绝，尚不能确认是地址还是端口限制；请使用兼容 IP 与相同端口对照。确实只接受低端口的车机，不能承诺由此模式解决。特斯拉、萤火虫及其他车型需独立实测。

此模式依赖部分 ROM 对已停用 TUN 地址的保留行为，可能与其他 VPN 冲突；地址已配置不等于车机可达。HTTPS 仍需可信证书，WebRTC 需另测。正式发布不改变该功能的实验属性。

## 安装
下载 WheelPlay-Xpeng-v1.0.1.apk。不要卸载旧版或清除数据；公开 APK 不包含认证资源，已有导入数据可随覆盖安装保留。安装后关闭车机旧标签并重新打开。

1.0 用户先手动下载覆盖。RC6 用户可在设置 → 应用更新检查本正式版。首次系统安装授权后返回再次点击安装；安装中断当前投屏，请停车后操作。
