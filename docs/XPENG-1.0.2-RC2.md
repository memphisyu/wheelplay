# 1.0.2 RC2：上游测试适配与验证补充

本版提供包含最新源码的可覆盖安装 APK，基于 1.0.2 RC1。实际投屏、音频和连接功能沿用 RC1，不将测试改动描述为新增播放或断连修复。

## 本次更新
- 选择性适配上游 4ed3536，修复 RTC 仪器测试的参数调用。
- 增加当前小鹏版网页入口、配对页面与媒体/FLAC 音频资源的 Android HTTP 检查。
- 增加 Android API 28/36 模拟器 CI；完整运行结果以 GitHub Actions 为准。
- 记录上游合并台账与后续分支同步策略；Compose 和整套双语迁移继续暂缓。

## 安装
版本 1.0.2-rc.2 / versionCode 40，沿用原包名和发布签名。安装 **WheelPlay-Xpeng-v1.0.2-rc.2.apk** 覆盖既有小鹏定制版，不要先卸载或清除数据。公开 APK 不内置认证资源。App 内检查更新时需开启包含 RC 预发布版本。

保留 RC1 的连接修复及默认关闭的可选 mDNS；.local 入口仍依赖车机解析与热点多播支持，不替代原受信任 HTTPS 域名。建议继续验证 G9/15T 锁屏连接、持续音乐、封面与方向盘、分屏/全屏切换。

本版为预发布候选版，1.0.1 继续保留为正式版。GitHub 和 Gitee 同步提供 APK、源码 ZIP 与 SHA-256 校验文件。
