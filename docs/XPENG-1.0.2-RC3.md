# 1.0.2 RC3：视频修复、缩放补偿与画面恢复

基于 1.0.2 RC2，按维护者确认范围选择性适配四个上游提交：`8336242`、`c626661`、`a417a64`、`44635dd`。本版不引入 WebP/v3 图片流水线、直接 Canvas、Compose 设置迁移或整套双语资源。

## 改动与使用

- **视频帧格式修复：** Native 入口明确将输入作为长度前缀记录处理，避免部分 256–511 字节 NAL 被错当 Annex B，影响 H.264/HEVC 解码。它是视频修复，不代表音乐链路问题已解决。
- **可选浏览器缩放补偿：** 车机连接页新增「忽略浏览器缩放」，默认关闭，当前浏览器记住选择。遇到浏览器放大导致的显示/触控偏差时再尝试开启。尺寸按比例归一化并限制范围；保留小鹏版 800ms 尺寸上报等待、后台页面保护，以及现有尺寸重协商容差。明显窗口变化仍可能重连，选项不等于修改图标密度或保证消除黑边。
- **画面与触控分离：** 新网页协商媒体协议 v2，帧、状态、offer 和触控携带媒体会话/视频代号；旧视频或旧连接的迟到回调不能覆盖当前画面。短暂源恢复时保留最后画面、释放触点并暂停输入；两秒恢复窗口超时显示等待。此窗口不替代 WebRTC 4/10/30 秒容忍策略。旧网页继续使用原始 JPEG/旧触控协议。
- **WebRTC 回退后自动重试：** 回退 JPEG 后按 5、10、20、30 秒退避重试。协商期间继续显示图片，首个视频画面到达后再接管；稳定显示一分钟才重置退避。不支持编码或浏览器永久拒绝时停止当前配置的重复尝试。此机制不是重新连接 iPhone，也不负责重启被系统终止的服务。

小鹏版音乐 MSE/FLAC、媒体信息、封面、方向盘控制、Root/后台连接、HTTPS/认证导入及应用更新模块继续保留。新增媒体快照不替代原歌曲信息快照。

## 安装

版本 `1.0.2-rc.3` / versionCode `41`，包名与签名沿用。使用 `WheelPlay-Xpeng-v1.0.2-rc.3.apk` 覆盖安装，不要先卸载或清除数据。升级后关闭车机旧标签，再重新打开地址以载入新的网页协议。首次回归建议保持原生 Video、H.264、30fps，并先不启用浏览器缩放补偿，随后逐项对照。

## 验证范围

自动回归包含 Native 长度边界/关键帧/坏记录及 RTP 往返、旧网页与新协议、媒体版本/触控隔离、退避策略、网页音乐/媒体控制既有测试；真实 Chromium + WebSocket 测试使用合成 JPEG 检查保帧、触控释放、恢复期限、重建、旋转和重连，不模拟真实 iPhone 或车辆。

G9/15T 仍需实车验证 H.264/HEVC 持续播放、分屏/全屏与浏览器缩放触控边缘、回退自动重试、音乐无声恢复、封面方向盘和锁屏后台。自动测试通过不能替代实车长播，也不保证所有车机浏览器支持同样行为。
