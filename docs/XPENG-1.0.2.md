# Wheelplay 小鹏定制版 1.0.2

## 使用变化

- 局域网发现默认开启，已有手动关闭的选择不变。
- 小鹏专属设置、更新下载、后台保活、作者与交流群入口及音频提示支持简体中文、英文和繁体中文，随 Android 系统语言选择。二维码原图及链接不改变。
- 浏览器页面统一显示 WheelPlay，删除“小鹏定制版”标识文案；保留必要的连接、播放和诊断提示。
- 日夜模式同时作用于投屏与浏览器，可从“画面与串流”或“浏览器与配对”调整。保留跟随 Android 和固定日夜选项，新增自定义时段（默认 18:30—07:00）及跟随车机浏览器。
- 跟随车机使用浏览器的主题信号，不是直接读取车机大灯或专有接口。如果浏览器不随车机切换，请选择时段模式；浏览器不提供主题信息时使用设定时段。时间使用 Android 宿主的本地时区，持续连接时边界切换可能延迟约半分钟。
- 旧的未使用媒体控制文件与对应孤立测试、测试装载引用已移除。实际播放控制仍使用统一媒体桥接。

## 升级

安装 WheelPlay-Xpeng-v1.0.2.apk 覆盖既有小鹏版，不先卸载。包名及签名不变，版本号 1.0.2 / versionCode 43。更新后关闭旧车机标签页并重新访问。公共包不包含认证或 HTTPS 私钥。
