# 1.0.3 RC1

本次为 1.0.3 RC1 预发布版，欢迎先行体验并反馈。

### 调整内容
- 新安装默认使用 80% 分辨率、30fps 协商帧率和 50 图片质量，降低画面处理及无线传输负担。
- 已保存的个人设置继续保留，不会因升级被覆盖。已有用户如需体验这组参数，请在“画面与串流”中手动调整。

### 升级说明
下载 WheelPlay-Xpeng-v1.0.3-rc.1.apk，直接覆盖安装，无需卸载。升级后关闭车机旧网页，再重新打开 App 显示的地址。

### 使用提醒
本次调整默认参数，不改变图片模式的实际帧率上限。导航位置停滞仍需结合诊断排查，尚不能确认本版已解决；G9 与 OnePlus 15T 的实际效果请以实车体验为准。

维护记录：版本号 1.0.3-rc.1，versionCode 44。仅修改默认分辨率比例、协商帧率与图片编码质量；已有偏好不迁移、不覆盖。相关缩放、显示设置与图片编码既有单元测试通过；Release 构建通过，lint 0 错误、25 条既有警告。保留原包名、签名及设置首页两张二维码。
