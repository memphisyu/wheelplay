# 1.0.3 RC2 候选版：显示尺寸调整

- 提供“更小、小、中、大、更大”五档显示尺寸，原有小／中／大档位的尺寸值保持不变。图标仍嫌小时，可选择“更大”。
- 停用旧版隐藏的画布缩放值，避免与当前显示尺寸叠加；保留已保存的显示尺寸、分辨率及其他设置。
- 保留分屏／全屏的物理尺寸稳定计算，不恢复依赖历史最大窗口的旧算法。
- 延续 RC1 的默认参数：80% 分辨率、30fps 协商帧率、图片质量 50；已有偏好不覆盖。

覆盖安装后关闭旧网页并重新连接 iPhone，在“画面与串流”中选择尺寸。更大档位可能改变应用布局，实际效果需要 G9／15T 验证。本次未确认导航位置停滞问题得到解决。

维护记录：versionCode 45；物理宽度分别为更小 400mm、小 350mm、中 300mm、大 250mm、更大 200mm。设置以毫米保存，不依赖新增枚举的序号。旧 ui_scale_percent 在读取时移除，统一返回 100%；不改写物理宽度或分辨率。发布为预发布版；相关回归测试通过，Release 构建通过，lint 0 错误、25 条既有警告。实车效果待验证。
