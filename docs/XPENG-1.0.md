# Wheelplay 小鹏定制版 1.0

基于 audio9，统一应用名称为 Wheelplay 小鹏定制版。versionName 1.0，versionCode 30，包名 moe.feng.wheelplay.xpengaudio 与签名保持一致，可覆盖已有安装。使用 release 构建，关闭 debuggable，保留原功能与配置迁移。

清理主界面、应用名称和网页中的测试版/实验性称谓；媒体诊断的有声校验改称音频检查，保留诊断功能。MSE 音乐、封面、方向盘媒体控制、后台准备连接和相近比例调整功能延续 audio9。

公开 APK 不内置认证身份，覆盖已有安装可继续使用导入的认证资源和 HTTPS 设置。首次安装需自行配置。后台连接需提前完成授权/配对、启用开机启动和自动连接并应用 Root 保活；域名解析需对应当前设备 IP。锁屏背景路径、麦克风、Siri 和厂商冻结行为仍依赖设备策略，正式发布不构成兼容保证。
