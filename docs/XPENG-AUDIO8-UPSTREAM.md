# audio8 上游同步测试版

合入 fython/wheelplay main 的 96a13de 和 cf78e4d，保留 audio6 MSE 音乐、audio7 封面、XPENG 默认名称/图标与锁屏保护。包名与签名沿用，versionCode 28。

新增车厂名称和图标自定义、日夜模式、iPhone/Android 定位来源、Android/浏览器/禁用麦克风、音频输出、安全区域和浏览器离线策略；修复热点名称含空格时的保存问题。旧浏览器音频和麦克风选择保留迁移。

公开 APK 不包含配件认证身份；已有安装可覆盖保留数据。安装后关闭旧浏览器标签重开。设置音频输出为车机浏览器，先使用 Android 麦克风或禁用麦克风；切换麦克风需重新连接。浏览器离线策略先保持默认保持连接。

回归：mse-flac 音乐、车机歌曲信息、方向盘上一首/下一首、封面与连续切歌、浏览器断开后重连。再独立测试浏览器麦克风、Siri、锁屏和音量通道。新增功能不代表 G9 实车已验证。audio6/audio7 Release 保留供对照；Android 降版本可能需卸载，卸载会清除数据，先保管认证资源和证书。
