# audio9 后台启动与比例调整测试版

基于 audio8，保留已实测的封面和媒体控制。设置开启“开机自动启动”和“打开应用时自动连接”，提前完成无线模式、认证、通知与必要权限的配置。Root 保活需由 App 应用管理的省电豁免启用，不能仅以系统权限显示 Root 已授权为准。

服务正常启动后使用 START_STICKY；开机直接启动前台网页服务，不依赖后台拉起主界面。仅复查此前由 App 添加的 Root 省电豁免，复查失败记入 keepalive.log，不阻断网页服务。开机／系统恢复阶段不声明受后台限制的麦克风前台类型。系统强制停止或厂商冻结仍可能阻止启动，无法保证所有系统策略下恢复。

已配对车机浏览器连接后，如果启用了自动连接、无线模式和 App 管理的 Root 保活，而手机会话未建立，尝试通过 Root 请求初始化连接页面；锁屏／厂商策略下的效果待 OnePlus 15T 实测。仅对配对浏览器触发，30 秒冷却，不解锁或点亮屏幕。首次设备选择、权限或配对提示仍需手动完成。网页无法建立网络连接时无法触发该流程。

比例自适应参考 DashPlay closeShape（20% 相对宽高比容差）：相近比例保留原协商流，按现有页面适配显示，避免浏览器工具栏、全屏切换造成频繁重连；明显竖屏／分屏变化仍重协商。隐藏页面不报告尺寸，尺寸上报延迟 800 ms 稳定。保持原等比例显示与触控映射，不照搬 DashPlay 拉伸画面的策略，可能保留少量留白。手动修改分辨率等协议设置仍需重连。

测试：重启 15T 后等待解锁一次使凭据存储可用，再锁屏放入背包；G9 自动开启热点后，确认手机自动连接热点，在已配对车机浏览器访问原 HTTPS 地址。记录是否出现常驻通知、网页是否加载、手机互联是否开始。无法访问时先核对 DHCP IP 与域名解析。导出诊断及 keepalive.log；目前没有设备日志，不能认定故障是 Root 保活未执行。

再测试全屏／退出全屏、轻微窗口变化、明显分屏变化；验证歌曲、方向盘、封面、麦克风和重连。禁用麦克风适合作为首次后台连接对照。仅构建测试包，不覆盖现有 audio8 Release。
