# WheelPlay 小鹏媒体控制诊断测试版

版本：0.3.0-xpeng-audio5-media-probe，versionCode 25。

本版用于区分车机媒体接管问题与 CarPlay 命令链路问题。尚未确认修复 G9 方向盘或音量通道；真实 CarPlay 媒体仍沿用上一版 MediaStream 输出。普通播放器测试使用独立的真实有声 WAV 文件，不是 CarPlay 音乐。

## 安装与准备

1. 安装Release 附件中的 v0.3.0-xpeng-audio5-media-probe.apk，覆盖此前的小鹏音频测试版。包名和签名沿用；不用先卸载。关闭其他 WheelPlay 版本，更新后重新启动服务并刷新车机页面。
2. 停车测试，先调低音量。Android 开启“转发音频到浏览器”，先关闭“使用浏览器麦克风”。连接 iPhone 并播放音乐。
3. 车机启动页面不要勾选“连接后隐藏顶部栏”或“启动后隐藏顶栏并全屏”，以便打开顶部“查看媒体诊断”。已隐藏时刷新页面再启动。

## A：先验证 iPhone 控制链路

打开“查看媒体诊断”，暂不启动普通播放器测试。页面应显示“CarPlay 控制模式”。点击网页“下一首、上一首、暂停、播放”，观察 iPhone/CarPlay 是否实际执行。

诊断 media.commands 中：origin=page 为网页按钮，origin=media-session 为浏览器系统媒体回调。requestId 用于对应服务端回执。SENT 仅证明发送结果，不能单独证明 iPhone 已执行；结合实际切歌与 media.changes 判断。UNAVAILABLE 表示当前控制源不可用，SUPERSEDED 表示连接代次不符，FAILED 表示发送失败，NOT_SENT 表示网页未能发出，TIMEOUT 表示 5 秒未收到回执。断线不会重放命令。

## B：验证车机能否接管普通播放器

点击“开始普通播放器测试”。本版暂停浏览器 CarPlay 音频、释放实际麦克风及旧播放输出，播放约 30 秒的短促测试音。面板显示“普通播放器测试模式”，其中上一首/下一首现在切换两种测试音，不控制 iPhone。

1. 看 G9 系统媒体卡片是否显示“WheelPlay 媒体测试 1/2”；调整音量，记录属于媒体还是语音通道。
2. 按方向盘上一首、下一首、播放/暂停。查看 probe.events 是否出现 type=action、origin=media-session，以及实际播放变化。
3. 取消“显示普通播放器”复选框，再比较方向盘是否工作。该选项仅切换播放器可见性。
4. 点“结束测试并恢复 CarPlay”。测试音播放完毕也会自动退出；暂停等情况下最多保留两分钟后退出。确认 CarPlay 音乐恢复、网页按钮重新控制 iPhone。

probe.source=wav-blob 表示普通文件播放器。probe.registered 只说明动作注册成功，不能证明车机已经接入。capabilities 中 file/mse 仅是浏览器报告的格式支持能力，不代表 AAC 流已实测可用。

## C：保存结果

点击“导出诊断 JSON”。若 G9 无法取出下载文件，拍摄关键诊断区域，并记录：服务设备、车机版本、普通播放器是否出现系统卡片、音量通道、方向盘各按钮结果、网页切歌是否有效、结束测试后音乐是否恢复。

判断：普通播放器成功而 CarPlay 失败，优先推进真实媒体编码流；网页按钮失败，先修命令链路；普通播放器也失败，继续调查车机浏览器与系统媒体桥接。开启浏览器麦克风/Siri 后的音量通道恢复另行对照测试。

本机自动化与浏览器验证不能替代 G9 实测。旧版 audio4 Release 保留作为回退；旧版 versionCode 较低，通常不能直接覆盖新版降级，需按设备安装限制处理。
